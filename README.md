# RatelPlus Inventory Management API

Enterprise-grade Inventory Management System built with NestJS, Prisma, and PostgreSQL.

## Features

- Authentication & RBAC
- Warehouse Management
- Inventory Management
- Equipment Assignment Tracking
- Maintenance Management
- Stock Movement Tracking
- Dashboard Analytics
- Audit Logging
- Swagger API Documentation
- Email Service

## Tech Stack

- NestJS
- Prisma ORM
- PostgreSQL
- JWT Authentication
- Swagger/OpenAPI

## Architecture

Modular enterprise architecture with:

- Domain-driven modules
- Repository pattern
- DTO validation
- Transactional workflows
- Audit logging
- Role-based authorization

## Setup

### Install dependencies

```bash
pnpm install
```
